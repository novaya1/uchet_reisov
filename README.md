# Учёт рейсов

Готовая папка проекта для GitHub Pages.

Внутри 6 файлов:
- `index.html` — страница приложения
- `style.css` — оформление
- `app.js` — логика приложения
- `manifest.webmanifest` — установка как веб-приложение
- `sw.js` — работа офлайн после первого открытия
- `README.md` — эта инструкция

Загрузите все 6 файлов в корень репозитория GitHub и включите GitHub Pages.
