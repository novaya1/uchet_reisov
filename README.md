# Учёт рейсов

Готовый статический сайт для GitHub Pages.

## Как опубликовать
1. Создайте новый репозиторий на GitHub, например `uchet-reisov`.
2. Загрузите в него все файлы из этой папки.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Deploy from a branch.
5. Branch: `main`, folder: `/ (root)` → Save.
6. GitHub выдаст ссылку на сайт.

Данные рейсов сохраняются в браузере конкретного устройства через localStorage.
